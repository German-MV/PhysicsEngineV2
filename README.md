# PhysicsEngineV2

This is a toy physics engine created by Germán Marín Valenzuela, a physics graduate from the University of Zaragoza.

This engine includes some basic physics objects such as particles and rigid bodies, which can be handled using forces and constraints through the XPBD algorithm.

It does not have a collision detection and handling system yet, but it might be implemented in future updates.

I also plan to implement a rendering system with OpenGL (as I did for the previous version of this PhysicsEngine), but for now it uses simple graphics in the console.

I am open to suggestions for improving this engine. Its main objective is to learn more about how physics engines work and about the C++ programming language.
